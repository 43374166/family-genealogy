# 参考材料

- `项目开发规划报告.docx`：产品范围、角色权限、数据模型、页面规划与开发阶段。
- `ui-home.png`：首页视觉参考（水墨背景、概览、快捷入口、最新动态、底部导航）。
- `ui-tree.png`：族谱树视觉参考（世代筛选、纵向世系、缩放控件、人物摘要卡）。

## 使用说明

- 这些图片只作为设计方向，不作为 App 运行时资产。
- App 里的水墨头图、树纸背景和人物肖像均由
  `apps/mobile/tool/generate_assets.py` 程序化绘制，避免直接使用截图或未授权照片。
- 族谱数据均为虚构演示数据；首页与族谱页统一使用「张氏家族」，并未照搬参考图中的混用姓氏。
