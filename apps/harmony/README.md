# apps/harmony · 鸿蒙端（技术验证，尚未开始）

鸿蒙适配必须独立评估，不能因为 Flutter 代码可编译就认为插件、文件选择、网络、
推送和发布流程都可用。

## 待验证清单

1. Flutter for OpenHarmony 三方方案的目标 HarmonyOS 版本与维护状态。
2. 现有依赖（网络、图片、本地存储、权限）的鸿蒙替代实现。
3. DevEco Studio 工程签名、HAP 打包与真机安装。
4. 中文字体、状态栏安全区、系统返回手势。
5. 微信登录、文件上传等外部能力是否可用。

在验证完成前，不承诺鸿蒙交付时间，也不把 Flutter UI 直接视为鸿蒙成品。
