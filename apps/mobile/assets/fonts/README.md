# Fonts

`NotoSerifSC-SemiBold.ttf` is Noto Serif SC, used only for display headings and
the family seal.

- Source: Google Fonts (https://fonts.google.com/noto/specimen/Noto+Serif+SC)
- License: SIL Open Font License 1.1, see `OFL.txt`
- The font is bundled so Android and iOS render the same serif Chinese headings
  without depending on system CJK fonts.
